# Requirements

## Functional

- Retrieve data from the World Bank Indicators API for configured countries and indicators.
- Preserve raw responses with extraction timestamps.
- Clean and normalize records.
- Harmonize country codes, names, years, and units.
- Validate data quality with a publication gate.
- Publish CSV, Parquet, and DuckDB datasets.
- Generate a data dictionary and quality report.
- Generate charts and SQL analytics.
- Run automated tests.

## Non-functional

- Runs locally with free tools.
- No secrets required.
- Reproducible from a clean environment.
- Clear documentation and engineering rationale.
